# 심어봄 제품 방향

## 핵심 정의

심어봄은 식물을 처음 키우는 사용자가 자신의 공간과 생활 조건에 맞는 시작 방법을 찾고, 작은 화분에서 베란다와 텃밭까지 재배 범위를 확장하도록 돕는 초보자용 식물 생활 가이드다.

## 사용자 성장 흐름

```text
시작 진단
→ 재배 공간 선택
→ 식물 추천
→ 배치·준비 안내
→ 관리 일정
→ 기록
→ 다음 단계 추천
```

재배 공간은 하나의 공통 개념 아래에서 단계적으로 확장한다.

1. 실내 화분
2. 베란다
3. 텃밭

각 공간은 크기, 일조 환경, 재배 식물, 관리 일정, 물주기 기록과 성장 기록을 공통으로 관리한다.

## 핵심 기능 범위

### 1단계: MVP

- 공간이 없는 초보자를 위한 시작 진단
- 실내 화분·베란다·텃밭 선택
- 공간, 햇빛, 관리 가능 시간 입력
- 조건에 맞는 식물 추천
- 준비물, 예상 비용과 시작 방법 안내
- 화분·베란다의 기본 관리 일정
- 텃밭 격자 배치·수량 계산과 화분·베란다 대표 작물 관리
- 물주기·작업·성장 기록
- 다음 재배 단계 추천

### 2단계: 식물과 꽃 관리 확장

- 일반 화분과 모종 관리
- 꽃다발의 꽃 종류 직접 선택
- 꽃다발 관리 방법 안내
- 받은 날짜와 상태에 따른 예상 감상 기간 범위 제공
- 꽃다발에서 직접 키우기 쉬운 식물로 연결

꽃다발은 뿌리를 내려 재배하는 식물과 생명주기 및 관리 규칙이 다르므로 별도 기능 영역으로 관리한다.

### 3단계: 사진 분석

- 사진으로 식물·꽃 후보 판별
- 사용자가 후보 중 실제 종류 확인
- 꽃의 현재 상태 분석
- 남은 감상 기간 범위 추정
- 병해충 후보와 대응 방법 안내

사진 분석 결과는 단정하지 않고 신뢰도, 후보와 주의 문구를 함께 제공한다. 꽃의 수명은 종류, 절화 시점, 온도, 수분과 현재 상태에 따라 달라지므로 정확한 날짜가 아닌 범위로 안내한다.

### 4단계: 재배용품 구매 연계

- 추천 식물과 공간에 맞는 준비물 목록 생성
- 화분, 배양토, 모종, 씨앗, 비료와 재배 도구 추천
- 사용자가 보유한 물품을 제외한 구매 목록 제공
- 상품 비교와 외부 판매처 연결
- 향후 서비스 내부 장바구니와 결제 지원
- 재배 단계와 계절에 맞는 소모품 재구매 알림

구매 기능은 상품을 먼저 노출하는 방식이 아니라 사용자의 재배 계획에서 실제로 필요한 물품만 제안하는 방식으로 설계한다.

```text
공간과 식물 선택
→ 필요한 물품 자동 계산
→ 보유 물품 제외
→ 구매 목록 확인
→ 외부 판매처 또는 내부 결제
```

## 기능 영역 경계

```text
심어봄
├─ 식물 키우기
│  ├─ 실내 화분
│  ├─ 베란다
│  └─ 텃밭
├─ 꽃 오래 보기
│  ├─ 꽃다발 등록
│  ├─ 관리 안내
│  └─ 예상 감상 기간
└─ 재배 준비
   ├─ 준비물 목록
   ├─ 상품 추천·비교
   └─ 구매·결제
```

식물 키우기, 꽃다발 관리와 상품 구매는 서로 다른 규칙과 책임을 가지므로 각각 독립된 기능 영역으로 유지한다. 식물 기준 정보와 사용자 일정처럼 실제로 공유되는 데이터만 공통으로 사용한다.

## 현재 우선순위

1. 핵심 사용자와 요구사항 확정
2. 공간 기반 시작 진단
3. 화분·베란다·텃밭의 공통 데이터 구조
4. 대표 식물과 작물 기준 데이터
5. 텃밭 배치 및 규칙 검증
6. 관리 일정과 기록
7. 꽃다발 관리
8. 사진 분석
9. 재배용품 구매 연계

꽃다발 사진 분석과 내부 쇼핑·결제는 핵심 재배 경험이 안정된 이후에 구현한다.

## 무료 유입과 구독 가치

심어봄은 기본 식물 정보를 유료로 잠그지 않는다. 처음 방문한 사용자가 바로 문제를 해결하고, 식물을 등록한 뒤 반복 관리로 이어지게 만든다.

```text
선물 받은 꽃 응급 관리·기본 식물 정보
→ 내 식물과 공간 등록
→ 물주기·분갈이·수확 일정과 기록
→ 날씨·지역·생육 상태를 반영한 능동 관리
```

### 무료

- 선물 받은 꽃 응급 관리
- 기본 식물·꽃 정보
- 제한된 공간과 시즌 등록
- 기본 재배 일정과 앱 내부 알림

### 프로

- 날씨·지역·생육 상태에 따른 일정 자동 조정
- 사진 기록 변화 비교와 이상 징후 안내
- 무제한 식물과 가족 공동 관리
- 앱을 열지 않아도 받는 푸시 알림
- 시즌별 관리·성장 리포트

프로 요금제는 정적인 정보의 양이 아니라 사용자가 놓치기 전에 먼저 알려 주고, 환경 변화에 맞춰 계획을 다시 계산하는 데 가치를 둔다. 실제 결제는 Laravel 사용자 데이터, 날씨 연동, 사진 저장·분석, 알림 발송과 공동 관리가 구현된 뒤 연결한다.
