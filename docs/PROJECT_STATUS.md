# 심어봄 현재 구현 상태

기준일: 2026-08-19. 상태가 바뀌는 기능 작업에서는 이 문서도 함께 갱신합니다. 세부 동작은 코드와 테스트가 최종 기준이며, 진행 중 브랜치와 다음 작업은 [작업 목록](TASKS.md), 상세 인계는 [작업 인계서](HANDOFF.md)를 확인합니다.

## 핵심 사용자 흐름

현재 다음 흐름은 Laravel API와 DB에 연결되어 있습니다.

```text
회원가입·로그인
→ 공간 등록
→ 시즌 등록
→ 작물 정보 탐색
→ 텃밭 격자·작물 배치 또는 화분·베란다 작물 선택
→ 재배 일정 생성·완료
→ 물주기 일정·완료·미루기
→ 작업·성장·수확 시즌 기록
→ 대시보드 일정 확인
```

## 구현 완료

### 인증

- 회원가입, 이메일 중복 검사, 로그인·로그아웃, 현재 사용자 조회
- 회원 본인 탈퇴(`DELETE /me`) — 계정을 비활성화하고 세션·API 토큰을 종료, 재배 데이터는 보존
- Laravel Socialite 기반 Google 로그인과 기존 이메일 계정 연결
- Kakao REST OAuth 기반 카카오 로그인, 검증 이메일 계정 연결과 provider별 실패 처리
- 비밀번호 해시 저장과 Sanctum 세션 인증
- 비로그인 관리 화면 접근 제한과 로그인 후 원래 경로 복귀

### 기준정보와 계획

- 대표 작물·꽃 기준정보, 검색·분류·공간 필터, 출처 표시
- 재배 공간 CRUD와 사용자 소유권 검사
- 현재 위치 또는 카카오 주소 좌표와 공간 방향을 이용한 예상 일조 시간 추천
- 재배 시즌 CRUD, 상태 계산, 기간 겹침 방지
- 텃밭 격자·작물 배치·포기 수 계산
- 화분·베란다 대표 작물 선택 후 격자 없이 일정 생성
- 포기 간격, 재배 시기, 연작 위험 경고

### 일정과 기록

- 배치 작물 기준 심기·수확 일정 생성
- 일정 완료·되돌리기·개별 및 전체 삭제
- 물주기 반복 일정 CRUD, 완료·미루기·완료 취소와 이력
- 작업·성장 관찰·수확·물주기 시즌 기록 CRUD
- 대시보드에서 재배 일정과 물주기 일정 통합 알림
- 매일 07:00 오늘 기한인 재배 일정·물주기를 회원에게 메일로 안내(`notifications:send-daily-reminders`, 큐 발송)

### 데이터 안전과 품질

- 사용자별 데이터 분리와 다른 사용자 접근 차단
- `ETag`, `If-Match`, 트랜잭션을 통한 동시 수정 충돌 방지
- 프론트엔드 strict TypeScript, ESLint, 단위·API 클라이언트 테스트
- Laravel 인증·소유권·경계값·부작용 기능 테스트와 Pint
- 회원가입부터 시즌 기록까지 실제 세션과 DB를 관통하는 Laravel API 통합 테스트
- GitHub Actions에서 Laravel과 Next.js 전체 검증 자동 실행
- ESLint에서 순환 의존성, 계층 침범, 복잡도와 중첩 한도 검사
- 반응형 화면과 주요 빈 상태·오류 상태
- `backend/resources/openapi.yaml` 단일 명세를 사용하는 공개 Swagger UI와 명세 제공 경로

### 사용자 화면 디자인 개편

- 디자인 시안의 온실 사진·에메랄드·따뜻한 흰색·둥근 카드 언어를 공통 기준으로 문서화
- 대시보드의 전체 폭 히어로, 공간별 재배 계획, 단일 시즌 여백 보정
- 마당·텃밭 작물 배치 상세 작업 화면의 정보·보드·가이드 구조
- 재배 일정의 타임라인·진행 현황·빠른 작업 사이드바
- 재배 공간 목록의 현황 요약과 공간 카드
- 재배 공간 등록·수정의 단계형 입력과 데스크톱 요약 사이드바
- 시즌 목록의 현황 요약·공간 유형별 다음 단계와 등록·수정의 단계형 입력·반응형 요약
- 물주기의 시즌 현황 요약·일정 카드·등록 사이드바와 완료·미루기·이력 작업 흐름
- 시즌 재배 기록의 종류별 필터·시간순 타임라인·등록 사이드바와 카드 내부 수정·삭제 확인
- 작물 목록의 기준정보 현황·검색·공간·종류 필터·이미지 카드와 작물 상세의 재배 단계·꽃 관리·공식 출처
- 로그인·회원가입의 온실 사진 2열 패널, 모바일 폼 우선 배치, Google·카카오 소셜 로그인 버튼과 제공자별 오류 안내
- 시작 진단의 온실 사진 히어로, 단계형 질문 카드와 진행 막대, 결과의 추천 식물·햇빛 안내·준비물·공간 등록 CTA
- 요금제의 `AppPageShell` 정합, 무료·프로 카드와 혜택별 제공 상태 배지, 결제 없음 안내
- 위 완료 화면의 데스크톱·모바일 시각 확인과 기존 기능 회귀 검증
- CSS 도형이던 브랜드 마크를 새 로고 이미지로 전면 교체(프론트 헤더·푸터·랜딩·인증 화면, 관리자 콘솔 사이드바·로그인), 사진 위 대시보드 헤더는 흰색 로고 변형으로 대비 확보, 파비콘·오픈그래프 이미지 갱신
- 삭제·초기화 등 되돌릴 수 없는 동작을 브라우저 기본 확인창 대신 공용 `InlineConfirm` 카드 내부 확인으로 통일(재배 공간·시즌·물주기 일정·재배 일정·격자 초기화)
- 오류 메시지 색을 `--color-danger` 토큰으로 통일하고 목록·워크스페이스 오류에 다시 시도 버튼 추가
- 재배 공간·시즌 수정 화면이 데이터 로딩 중 "찾을 수 없음" 오류를 잘못 보여 주던 버그 수정
- 사진 위 대시보드 헤더의 계정 메뉴가 흰 배경에 흰 글자로 보이지 않던 문제 수정
- 모바일 내비게이션을 앱 헤더와 동일한 가로 스크롤 패턴으로 통일하고, 동작하지 않던 홈 화면 햄버거 버튼과 미사용 랜딩 컴포넌트 4개를 제거

### 시작 진단과 요금제

- 공간·햇빛·관리 시간·목적 4단계 진단과 공간 유형별 시작 안내
- 추천 식물을 하드코딩 목록이 아니라 작물 기준정보에서 선택하고 각 추천을 작물 상세로 연결
- 관리 시간과 맞지 않는 추천에는 주의 문구를, 공간에 맞는 기준정보가 없으면 다른 공간과 시작 가능한 식물을 안내
- 무료·프로 기능 비교와 혜택별 제공 상태 표시, 결제 미연결 사실의 명시

### 현재 작업 상태

- 시작 진단·요금제 디자인 통일, 로고 전면 교체, OpenAPI 갱신, 공통 빈 상태·오류·로딩·삭제 확인·모바일 내비게이션 통일을 완료
- 현재 미완성 로컬 디자인 변경은 없으며, 진행 상태와 다음 우선순위는 [작업 목록](TASKS.md)을 단일 기준으로 관리
- Swagger는 닷홈 업로드를 마쳐 운영 `/api-docs`와 `/api-docs/openapi.yaml`이 정상 응답(이메일 중복 확인·소셜 로그인 명세 포함)
- 카카오 로그인은 닷홈 변경 파일 업로드와 Kakao Developers 설정을 마쳐 운영에서 회원가입까지 정상 동작

### 기록 사진

- 시즌 기록마다 사진 한 장 등록·교체·삭제, JPG·PNG·WEBP 5MB 제한
- 저장 파일명은 서버가 생성하고 업로드 폴더에서 코드 실행을 차단
- 기록을 지우거나 사진을 바꾸면 이전 파일도 함께 삭제

### 관리자 운영

- Laravel Blade 기반 관리자 전용 로그인과 운영 대시보드
- 회원·공간·진행 시즌·미완료 일정·최근 활동 기록 운영 지표
- 기한 초과 일정, 일정 없는 진행 시즌, 위치 미설정 공간, 실패한 백그라운드 작업 점검
- 회원 검색·상태 필터와 일반 회원 비활성화
- 회원 비활성화 시 기존 세션과 API 토큰 종료
- 회원 상세 화면에서 공간별 시즌, 배치 작물과 포기 수, 격자 사용 칸, 일정 완료율, 기록 종류별 건수와 누적 수확량 확인
- 작물 기준정보와 공식 출처·검토일 조회
- 명령어를 통한 기존 활성 회원의 관리자 승격

## 출시 전 필수

출시 전 남은 항목과 완료 표시는 [작업 목록](TASKS.md)에서 관리합니다. 운영 도메인, HTTPS, Sanctum 쿠키, CORS 환경의 로그인 검증은 닷홈 배포 리허설에 포함합니다.

## MVP 후속

- 비밀번호 재설정
- 탈퇴 회원 개인정보 익명화(처리방침에 파기 조항이 생기면 진행, [관리자 콘솔 계획](ADMIN_CONSOLE_PLAN.md) 2번 참고)
- 시즌 마감 스냅샷·요약 리포트
- 웹 푸시 알림(프로 요금제용), VAPID 키·서비스워커·구독 저장
- 알림 읽음 상태와 사용자 설정
- 관리자 작물·재배 규칙 편집, 공개 상태와 감사 로그
- 실제 건물·나무 음영과 날씨·생육 상태를 반영한 일조·일정 조정

## 장기 확장

- 공동 텃밭 초대·역할·활동 로그
- 무료·유료 요금제, 구독·결제·환불·웹훅
- PDF 출력
- 꽃다발 관리와 사진 분석
- 재배용품 추천·구매 연계

장기 기능을 화면만으로 모의 구현해 완료된 기능처럼 표시하지 않습니다. 인증·권한·결제·파일·알림은 서버 보장과 실패 테스트가 함께 있어야 완료입니다.
