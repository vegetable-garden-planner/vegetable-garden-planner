# 심어봄 현재 구현 상태

기준일: 2026-08-12. 상태가 바뀌는 기능 작업에서는 이 문서도 함께 갱신합니다. 세부 동작은 코드와 테스트가 최종 기준입니다.

## 핵심 사용자 흐름

현재 다음 흐름은 Laravel API와 DB에 연결되어 있습니다.

```text
회원가입·로그인
→ 공간 등록
→ 시즌 등록
→ 작물 정보 탐색
→ 재배 공간 격자와 작물 배치
→ 재배 일정 생성·완료
→ 물주기 일정·완료·미루기
→ 작업·성장·수확 시즌 기록
→ 대시보드 일정 확인
```

## 구현 완료

### 인증

- 회원가입, 이메일 중복 검사, 로그인·로그아웃, 현재 사용자 조회
- Laravel Socialite 기반 Google 로그인과 기존 이메일 계정 연결
- 비밀번호 해시 저장과 Sanctum 세션 인증
- 비로그인 관리 화면 접근 제한과 로그인 후 원래 경로 복귀

### 기준정보와 계획

- 대표 작물·꽃 기준정보, 검색·분류·공간 필터, 출처 표시
- 재배 공간 CRUD와 사용자 소유권 검사
- 현재 위치 또는 카카오 주소 좌표와 공간 방향을 이용한 예상 일조 시간 추천
- 재배 시즌 CRUD, 상태 계산, 기간 겹침 방지
- 공간 유형별 격자·작물 배치·포기 수 계산
- 포기 간격, 재배 시기, 연작 위험 경고

### 일정과 기록

- 배치 작물 기준 심기·수확 일정 생성
- 일정 완료·되돌리기·개별 및 전체 삭제
- 물주기 반복 일정 CRUD, 완료·미루기·완료 취소와 이력
- 작업·성장 관찰·수확·물주기 시즌 기록 CRUD
- 대시보드에서 재배 일정과 물주기 일정 통합 알림

### 데이터 안전과 품질

- 사용자별 데이터 분리와 다른 사용자 접근 차단
- `ETag`, `If-Match`, 트랜잭션을 통한 동시 수정 충돌 방지
- 프론트엔드 strict TypeScript, ESLint, 단위·API 클라이언트 테스트
- Laravel 인증·소유권·경계값·부작용 기능 테스트와 Pint
- 회원가입부터 시즌 기록까지 실제 세션과 DB를 관통하는 Laravel API 통합 테스트
- GitHub Actions에서 Laravel과 Next.js 전체 검증 자동 실행
- ESLint에서 순환 의존성, 계층 침범, 복잡도와 중첩 한도 검사
- 반응형 화면과 주요 빈 상태·오류 상태

### 관리자 운영

- Laravel Blade 기반 관리자 전용 로그인과 운영 대시보드
- 회원·공간·진행 시즌·미완료 일정·최근 활동 기록 운영 지표
- 기한 초과 일정, 일정 없는 진행 시즌, 위치 미설정 공간, 실패한 백그라운드 작업 점검
- 회원 검색·상태 필터와 일반 회원 비활성화
- 회원 비활성화 시 기존 세션과 API 토큰 종료
- 작물 기준정보와 공식 출처·검토일 조회
- 명령어를 통한 기존 활성 회원의 관리자 승격

## 출시 전 필수

1. 회원가입부터 기록까지 브라우저 기준 핵심 사용자 흐름 E2E 테스트
2. 닷홈 상품의 PHP·문서 루트·SSH·Composer·cron 지원 확인
3. 운영 도메인, HTTPS, Sanctum 쿠키, CORS 환경에서 로그인 검증
4. 운영 DB 백업·마이그레이션·롤백 절차 리허설
5. 오래된 화면 안내 문구와 실제 서버 저장 동작의 최종 문구 점검

## MVP 후속

- 비밀번호 재설정, 회원 탈퇴와 개인정보 처리
- 기록 이미지 업로드와 파일 저장소
- 시즌 마감 스냅샷·요약 리포트
- Laravel 스케줄러·큐와 이메일 또는 푸시 알림
- 알림 읽음 상태와 사용자 설정
- 관리자 작물·재배 규칙 편집, 공개 상태와 감사 로그
- 실제 건물·나무 음영과 날씨·생육 상태를 반영한 일조·일정 조정

## 장기 확장

- 공동 텃밭 초대·역할·활동 로그
- 무료·유료 요금제, 구독·결제·환불·웹훅
- PDF 출력
- 꽃다발 관리와 사진 분석
- 재배용품 추천·구매 연계

장기 기능을 화면만으로 모의 구현해 완료된 기능처럼 표시하지 않습니다. 인증·권한·결제·파일·알림은 서버 보장과 실패 테스트가 함께 있어야 완료입니다.
