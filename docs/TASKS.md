## 목록 관리 규칙

- `[ ]` 대기, `[-]` 진행 중, `[!]` 막힘, `[x]` 완료 상태를 사용합니다.
- 작업을 시작한 즉시 항목을 `[-]`로 바꾸고 브랜치 이름을 적습니다.
- 검증까지 끝난 작업은 같은 작업 안에서 즉시 `[x]`로 바꾸고 완료일을 적거나, 이후 인계 가치가 없으면 목록에서 제거합니다.
- 완료된 작업을 `[ ]`, `[-]`, “다음 작업”, “남은 작업” 상태로 남겨 두지 않습니다.
- 작업 상태를 바꾼 코드와 이 문서의 상태 변경은 같은 기능 커밋에 포함합니다.
- 진행 목록은 이 문서에만 두고 `README.md`, `PROJECT_STATUS.md`, `HANDOFF.md`에는 중복 목록 대신 이 문서 링크를 둡니다.
- 완료 기록은 최근의 중요한 항목만 최대 10개 유지합니다. 오래된 완료 이력은 Git 기록과 `HANDOFF.md`의 완료 표로 확인합니다.
- 관련 테스트·정적 검사·빌드를 통과하기 전에는 `[x]`로 표시하지 않습니다.
